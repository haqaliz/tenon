## Phase 1: Evidence bindings

- **Goal:** a `var`/`:=` binds a receiver type from an annotation/composite/factory.
- **Prerequisites:** `receiver-config`.
- **Files:** `go_scan.py`, tests.
- **Steps:**
  1. Write failing tests: `var c *pkg.Type`, `var c pkg.Type`, `c := &pkg.Type{}`,
     `var c = pkg.Type{}`; a `receivers` key for `stripe.NewClient` and `NewClient`; an unmapped
     factory is not evidence; a rebinding replaces/clears.
  2. Run — red; implement the `var`/`:=` evidence; green.
- **Validation:** `uv run pytest tests/locate/test_go_scan.py -k "receiver or evidence"`.
- **Commit:** `feat(locate): bind Go receiver types`

## Phase 2: Receiver chains and policy

- **Goal:** a selector chain on a bound receiver is rooted and certain.
- **Prerequisites:** Phase 1.
- **Files:** `go_scan.py`, `go_locate.py`, tests.
- **Steps:**
  1. Write failing tests: `client.Charges.New(...)` -> `(Client,Charges,New)` plus the intermediate
     `(Client,Charges)`; a field access; an untracked chain not certain; a receiver wins over a
     package alias; a `locate_go` operation/component case with a mapped chain.
  2. Run — red; implement `_receiver` and the selector-call hits; green; full suite.
- **Validation:** `uv run pytest tests/locate/test_go_*.py`; full suite.
- **Commit:** `feat(locate): locate Go receiver chains`

## Edge cases & error handling

- A pointer annotation unwraps.
- Rebinding clears without evidence; a tracked receiver wins over a package alias.
