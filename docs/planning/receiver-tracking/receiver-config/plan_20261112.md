## Phase 1: Config fields

- **Goal:** a validated read-only mapping on both configs.
- **Files:** the two configs, tests.
- **Steps:**
  1. Write failing tests: a valid mapping; a blank/whitespace key/value is a named `ValueError`; the
     mapping is read-only.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/locate/test_rust_config.py tests/locate/test_go_config.py`.
- **Commit:** `feat(locate): add the receiver mappings`
