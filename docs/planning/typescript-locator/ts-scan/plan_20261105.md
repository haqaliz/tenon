## Phase 1: Dependencies, discovery and the parser skeleton

- **Goal:** parse the eight extensions and skip the right directories; no hits yet.
- **Prerequisites:** none.
- **Files:** `pyproject.toml`, `uv.lock`, fixtures, `tests/locate/test_ts_scan.py`,
  `src/tenon/locate/ts_scan.py`.
- **Steps:**
  1. Add the dependencies. Spike: `Language(tsts.language_typescript())`,
     `Language(tsts.language_tsx())`, `Language(tsjs.language())`; `Parser(language).parse(bytes)`.
  2. Write failing tests: a `.ts` fixture with an SDK import yields at least one `modules` entry;
     a `node_modules/evil.ts` with the same text is ignored; a parse-error file contributes nothing.
  3. Run — red.
  4. Implement discovery, grammar selection, source lines and a `ScanResult` with `modules` (for now
     the files that import the SDK directly). No hits.
  5. Run — green.
- **Validation:** `uv run pytest tests/locate/test_ts_scan.py -k discovery`.
- **Commit:** `feat(locate): discover and parse TypeScript files`

## Phase 2: Imports and reachability

- **Goal:** root names from every import form and find the modules that reach the SDK.
- **Prerequisites:** Phase 1.
- **Files:** `src/tenon/locate/ts_scan.py`, fixtures, tests.
- **Steps:**
  1. Write failing tests: default/named/namespace/`import =`/`require` roots; subpath and scoped
     package matching; `import type` does not root; a relative import is local; a module imported
     transitively by an SDK importer is in `modules`; an unrelated module is not.
  2. Run — red.
  3. Implement import extraction (`import_statement` → `import_clause`/`named_imports`/
     `namespace_import`/`import_require_clause`, source string), `require` calls, relative-edge
     resolution (exact, + extensions, `/index.*`) and the reverse-edge BFS.
  4. Run — green.
- **Validation:** `uv run pytest tests/locate/test_ts_scan.py -k "import or reachable"`.
- **Commit:** `feat(locate): resolve TypeScript SDK imports and reachability`

## Phase 3: One-hop aliases

- **Goal:** `const client = new Stripe()` and friends are rooted; a second hop is not.
- **Prerequisites:** Phase 2.
- **Files:** `src/tenon/locate/ts_scan.py`, fixtures, tests.
- **Steps:**
  1. Write failing tests: `new Stripe()`, `Stripe()`, `= stripe`, `= stripe.charges`, object
     destructuring (`{ charges }`, `{ charges: c }`); a redeclaration drops the alias; a second hop

  2. Run — red.
  3. Implement the declarator walker with unwrapping for parenthesized/`as`/`satisfies`/non-null

  4. Run — green.
- **Validation:** `uv run pytest tests/locate/test_ts_scan.py -k alias`.
- **Commit:** `feat(locate): track one-hop TypeScript SDK aliases`

## Phase 4: Calls, object keys and attributes

- **Goal:** emit the four `SiteShape` evidence types with exact columns.
- **Prerequisites:** Phase 3.
- **Files:** `src/tenon/locate/ts_scan.py`, fixtures, tests.
- **Steps:**
  1. Write failing tests: a rooted `client.charges.create({ amount: 1 })` emits a `call` hit and a
     `keyword` hit at the key column; `{ "amount": 1 }` emits `dict_key` at the quote; a shorthand
     `{ amount }` emits `keyword`; `charge.amount` on a class alias emits `attribute`; an array of
     objects in an argument is walked one level; an unrooted call emits `rooted=False` hits.
  2. Run — red.
  3. Implement the call visitor, member-chain resolution (`member_expression`), object/array key

  4. Run — green.
- **Validation:** `uv run pytest tests/locate/test_ts_scan.py -k "shape or call or key or attribute"`.
- **Commit:** `feat(locate): emit TypeScript call, key and attribute evidence`

## Testing strategy

- Pure Python; tree-sitter parses committed fixtures. No Node, no network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- Fixtures live under `tests/fixtures/repos/ts-*` and are read-only.
- The decoy test asserts zero certain evidence, not just zero sites (the resolver test proves the
  final certainty).

## Environment & secrets

- The three wheels install from PyPI; tests afterwards need no network.
- No Node, no `tsc`, no npm.

## Edge cases & error handling

- A parse-error file is skipped, as T2 skips a Python `SyntaxError`.
- An undecodable file is skipped.
- A relative import that cannot be resolved is ignored; the module is not scanned.
- A redeclaration/reassignment drops the alias.
- A `$`-prefixed identifier is reported at its exact column; T3's boundary is a later fix.

## Agent execution notes

- Strict TDD; commit per phase. Use the tree-sitter S-expression dumps in the PRD/plan to inspect
  node kinds; do not guess field names.
- Do not change the shipped `Hit`/`Dynamic`/`ScanResult` types unless a missing field is proven.
- Do not add a new `DynamicKind`; reuse `STAR_KWARGS`, `GETATTR`, `ALIAS_CHAIN` (and `STAR_ARGS` if
  an array spread needs it).
- Checkpoint after Phase 4: the basic fixture yields the exact hit tuples before any resolver work.
