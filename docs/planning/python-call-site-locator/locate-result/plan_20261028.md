## Phases

### Phase 1: Types and reason enums (TDD)

- **Files:** `src/tenon/locate/result.py`, `src/tenon/locate/__init__.py`,
  `tests/locate/test_result.py`
- **Steps:**
  1. Write failing tests first:
     - `Site(path="a.py", line=1, column=1, shape="call", symbol="delete", line_text=None)` is
       constructible for all four `shape` values.
     - `LocateConfig(sdk_package="")` raises `ValueError`; `LocateConfig(sdk_package="stripe")`
       works with empty mappings; mappings are frozen (mutation raises).
     - Every value of `LocateReason` and `AmbiguityReason` is reachable from the enum.
  2. Implement `Enum` subclasses as `StrEnum` (matching `src/tenon/detect/record.py`), so
     serialization cannot emit `"Shape.CALL"`.
  3. `Site`, `AmbiguousGroup`, `LocateResult`, `LocateConfig` are `@dataclass(frozen=True,
     slots=True)`; sequences are tuples.
  4. `AmbiguousGroup.candidates` must be non-empty — raise `ValueError` in `__post_init__`.
  5. `LocateConfig.__post_init__` validates `sdk_package` is a non-empty dotted identifier; use a
     simple `re.fullmatch(r"[A-Za-z_][\w]*(\.[A-Za-z_]\w*)*", ...)`; do not import `packaging`.
  6. `__init__.py` re-exports: `locate`, `LocateConfig`, `LocateResult`, `Site`, `AmbiguousGroup`,
     `LocateReason`, `AmbiguityReason` (`locate` arrives in aspect 4; until then the import is
     omitted, not stubbed).
- **Validation:** `uv run pytest tests/locate/test_result.py`
- **Commit:** `feat(locate): add Site, AmbiguousGroup, LocateResult and reason vocabulary`

### Phase 2: Invariant, canonical order, byte-stable JSON (TDD)

- **Files:** `src/tenon/locate/result.py`, `tests/locate/test_result.py`
- **Steps:**
  1. Tests:
     - `LocateResult(reason=X, certain=(site,), ...)` raises `ValueError`;
       `LocateResult(reason=None, certain=(), ambiguous=())` raises `ValueError`.
     - The same three sites inserted in different orders produce identical `to_json()`.
     - Subprocess with `PYTHONHASHSEED=0` and `=1` produces identical bytes (copy the pattern in
       `tests/detect/test_record.py`).
     - `json.loads(result.to_json())` succeeds; the payload contains only JSON primitives.
  2. Implement ordering in `__post_init__`: `certain` and each `candidates` tuple sorted by
     `(path, line, column, symbol)`; `ambiguous` sorted by `(reason.value, symbol)`.
  3. `to_dict()` returns
     `{"change": change.to_dict(), "certain": [...], "ambiguous": [...], "reason": str|None}`.
  4. `to_json()` = `json.dumps(self.to_dict(), sort_keys=True, ensure_ascii=False,
     separators=(",", ":"))` (identical to `DiffResult.to_json`).
- **Validation:** `uv run pytest tests/locate/test_result.py`
- **Commit:** `feat(locate): canonical ordering and byte-stable JSON for locate results`

### Phase 3: Optional `tenon.toml` loader (S1)

- **Files:** `src/tenon/locate/config.py`, `tests/locate/test_config.py`
- **Steps:**
  1. Tests: a fixture `tests/fixtures/tenon.toml` with `[locate] sdk_package = "stripe"`,
     `[locate.operations] "DELETE /v1/charges/{id}" = "charges.delete"`, `[locate.fields]
     "Charge.amount" = "amount_cents"` round-trips into a `LocateConfig`.
  2. A file with no `[locate]` table or no `sdk_package` raises `ValueError` naming the missing key.
  3. Implement `load_config(path: str | Path) -> LocateConfig` with `tomllib.load`; return
     `LocateConfig(sdk_package=data["locate"]["sdk_package"], operations=data["locate"].get(
     "operations", {}), fields=data["locate"].get("fields", {}))`.
  4. **Cut rule:** if this phase needs more than ~40 lines of implementation plus tests, stop and
     leave `load_config` out — the PRD marks it should-have, and the in-memory config is the API.
- **Validation:** `uv run pytest tests/locate/test_config.py`
- **Commit:** `feat(locate): load LocateConfig from tenon.toml`

## Testing strategy

- Unit tests only, offline. Every acceptance criterion in the aspect spec maps to at least one test;
  list them by number in a comment above each test.
- Run `.venv/bin/python -m pytest -q` (full suite) before each commit, not only the new file.
- The hash-seed test uses `sys.executable` with `-c`, exactly like the detect suite.

## Edge cases

- `column` is 1-based and a **character** column. Aspect 1 only stores it; aspect 3 computes it.
  Do not add a conversion here.
- Two sites identical in `(path, line, column, symbol)` but different `shape` must still order
  deterministically: append `shape.value` as the final sort key.
- `line_text` may be `None`; it is excluded from sort keys.
- An `AmbiguousGroup` with a reason and zero candidates is a construction error, not an empty group.
