### Phase 1: Walk, reachability, result types (TDD)

- **Files:** `src/tenon/locate/scan.py`, `tests/locate/test_scan.py`
- **Steps:**
  1. Write `Hit`, `Dynamic`, `ScanResult` exactly as in the spec (`frozen=True, slots=True`,
     tuple fields; `ScanResult` sorted by `(path, line, column, shape, symbol)`).
  2. Tests for the walk: `scan(sdk_basic, "stripe")` scans `acme/billing.py` and
     `acme/reporting.py` and **not** `acme/unrelated.py`; `.venv`, `node_modules`, `build`,
     `dist`, `__pycache__` and dot-directories are skipped (add a throwaway
     `tests/fixtures/repos/sdk-basic/.venv/bad.py` that would fail parsing if scanned).
  3. Implement `_modules(root)` with `Path.rglob("*.py")` plus the skip set.
  4. Implement `_imports(tree)` returning `(direct: set[str], local: set[str])` per module:
     `import stripe` / `from stripe...` → direct; relative/absolute imports resolved against
     `root` and `root/src` → local module dotted names.
  5. Reachability: BFS from modules whose `direct` set contains the sdk package or a prefix of it
     (`stripe`, `stripe.charges`); follow local edges. Unresolvable local imports add no edge.
  6. Syntax errors: skip the file and continue (do not raise); record nothing. Add a test with a
     deliberately broken `.py` in `sdk-basic` (`acme/broken.py`) asserting the scan still returns
     the other hits.
- **Validation:** `uv run pytest tests/locate/test_scan.py`
- **Commit:** `feat(locate): scan only modules that reach the SDK package`

### Phase 2: Import bindings and one-hop aliases (TDD)

- **Files:** `src/tenon/locate/scan.py`, `tests/locate/test_scan.py`
- **Steps:**
  1. Tests: `import stripe` → `stripe`; `import stripe as st` → `st`; `from stripe import Stripe`
     → `Stripe`; `from stripe.charges import create` → `create`; a file importing an unrelated
     package yields no rooted names.
  2. Alias tests: `client = Stripe()` and `c = stripe.Stripe(...)` are rooted; `d = client` is
     rooted; `e = d` emits an `alias_chain` dynamic; `x = other()` is not rooted.
  3. Implement `_bindings(tree)` → `(rooted_names: set[str], classes: set[str])` where `classes`
     are names bound from `from <sdk> import X` (used by aspect 4 for attribute certainty).
  4. Implement `_aliases(tree, rooted_names, classes)`: single pass over module-level and function
     body `Assign` nodes in source order; RHS is a `Name` already rooted, or a `Call` whose callee
     is rooted/a rooted class. Store `{local_name: chain_root}`; a second assignment from an alias
     whose own chain length is ≥ 2 records `alias_chain`.
  5. Keep it file-local. A name imported from a local module is **not** rooted (the `sdk-basic`
     reporting fixture asserts this).
- **Validation:** `uv run pytest tests/locate/test_scan.py`
- **Commit:** `feat(locate): root names through SDK imports and one-hop aliases`

### Phase 3: The visitor (TDD)

- **Files:** `src/tenon/locate/scan.py`, `tests/locate/test_scan.py`
- **Steps:**
  1. Tests per shape, using `sdk-basic` and `sdk-dynamic`:
     - `call`: `client.charges.delete(...)` → `symbol="delete"`, `chain=("charges","delete")`,
       rooted.
     - `keyword`: `create(amount=..., currency=...)` → two hits, `chain=("charges","create")`,
       rooted.
     - `dict_key`: `create({"amount": 1, ...})` → hit for each string key,
       `chain=("charges","create")`, rooted.
     - `attribute`: `resp.amount` in `sdk-dynamic` → unrooted; `Charge(amount=1)` where `Charge` is
       SDK-imported → rooted (`classes` lookup).
     - `star_kwargs` / `star_args` dynamics for `**row` / `*args` in a rooted call.
     - `getattr(client.charges, "delete")` → `getattr` dynamic with `symbol="delete"`.
  2. Implement one `ast.NodeVisitor`:
     - `visit_Call`: compute the callee chain (`_chain(node.func)` → root name + attribute tail);
       if the root is rooted (binding), emit a `call` hit, then walk `keywords` (skip `**`), dict
       args (and dicts inside list/tuple args), `Starred` args, and `getattr` calls.
     - `visit_Attribute`: emit an `attribute` hit only when not already the callee of a `Call`
       (track a `parent_is_call` flag or handle attributes inside `visit_Call` and skip them in
       the generic visit).
  3. Deduplicate identical hits at the end (`set` of tuples, then sort) so a node visited twice
     cannot duplicate output.
  4. `symbol` for a `call` is the leaf attribute; for `keyword` the keyword name; for `dict_key`
     the string key; for `attribute` the attribute name.
- **Validation:** `uv run pytest tests/locate/test_scan.py`
- **Commit:** `feat(locate): visit calls, keywords, dict keys and attributes`

## Testing strategy

- Every scan test asserts on the full sorted `ScanResult`, not just "contains a hit": an extra
  unexpected rooted hit is a failure. Add a helper `calls(result)` / `keywords(result)` to keep
  assertions readable.
- The decoy assertion is the product-critical one: `record(amount=1)` appears as an unrooted hit
  and never as rooted.
- Run the full suite before each commit.

## Edge cases

- `ast.parse` with a BOM or non-UTF-8 file: read with `encoding="utf-8"`, on `UnicodeDecodeError`
  skip the file (count it as unscanned) rather than raising.
- `getattr(obj, name)` with a non-literal name: emit a `getattr` dynamic with `symbol=None`.
- `obj.method(...)` where `obj` is a rooted alias but the attribute tail is empty: not a call hit.
- `super().method()` / `self._client.method()`: unrooted by construction; do not attempt class
  resolution.
- Windows/absolute paths: always emit repo-relative paths with `/`, via
  `path.relative_to(root).as_posix()`.
- Symlinks: `rglob` does not follow directory symlinks by default; leave it that way.

## Agent execution notes

- This module must never `import` or `exec` scanned code, and must never write to the fixture
  trees. Aspect 4's test asserts mtimes are unchanged; keep scanning read-only.
- Do not resolve cross-file aliases. The `sdk-basic` reporting fixture is the documented limit.
- Keep `scan` free of certainty policy: it reports `rooted` plus dynamics; aspect 4 decides.
- If a fixture test becomes awkward because `ast` cannot see a construct, add the construct to the
  dynamics list rather than guessing its meaning.
