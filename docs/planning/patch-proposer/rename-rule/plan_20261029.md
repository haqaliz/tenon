## Phases

### Phase 1: The gate (TDD)

- **Files:** `src/tenon/propose/rules.py`, `tests/propose/test_rules.py`
- **Steps:**
  1. Failing table test over every `ChangeKind`: only `renamed` with a field name passes the gate;
     every other kind returns `()`.
  2. Tests for malformed records: `before=None`, `before=""`, `before == after` → `()`; no
     exception.
  3. Endpoint-rename test: method/path set, `before="/v1/charges"`, `after="/v2/charges"` → `()`.
  4. Request-body property rename regression: method/path set, `before="amount"`,
     `after="amount_cents"` → edits. The discriminator is the leading `/`, not scope alone.
  5. Implement `RuleProposer.propose(change, located, root) -> tuple[Edit, ...]` with `root`
     accepted and ignored (protocol symmetry). No file access: a test monkeypatches
     `Path.read_text` to raise if called.
- **Validation:** `uv run pytest tests/propose/test_rules.py`
- **Commit:** `feat(propose): gate the rename rule to field renames`

### Phase 2: Certain sites to edits (TDD)

- **Files:** `src/tenon/propose/rules.py`, `tests/propose/test_rules.py`
- **Steps:**
  1. Tests: two certain keyword sites → two edits in locator order; a `call` site → no edit;
     `dict_key` and `attribute` sites → edits; a site whose `symbol` differs from `before` → no edit.
  2. Duplicate certain sites (same path/line/column/shape) → one edit.
  3. Implement the loop: for each site in `located.certain`, keep `symbol == old` and shape in
     `{KEYWORD, DICT_KEY, ATTRIBUTE}`, emit `Edit(path, line, column, shape, old, new)`; dedupe by
     `(path, line, column, shape, old)` preserving order.
  4. Ignore `located.ambiguous` entirely; add a test that a result with only ambiguous groups → `()`.
- **Validation:** `uv run pytest tests/propose/test_rules.py`; full suite before commit.
- **Commit:** `feat(propose): turn certain rename sites into candidate edits`

## Testing strategy

- Pure: no fixture repos, no `tmp_path` reads. Build `Change` and `LocateResult` literals.
- The 13-kind table is the regression net.

## Edge cases

- A `renamed` record whose `before`/`after` are dicts (should not happen for `renamed`, but do not
  crash) → `()`.
- A certain site on a shape not in the editable set → skip silently here; assembly will list it as
  `SHAPE_NOT_EDITABLE` only for `CALL`, which is the realistic case.
- Unicode names: `len(old)` is only used by verification, not here.
