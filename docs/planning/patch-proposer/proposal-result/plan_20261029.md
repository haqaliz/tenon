## Edge cases

- `Skipped` entries may repeat the same site with different reasons; do not dedupe in this aspect
  (assembly dedupes by `(path, line, column, reason)`).
- An edit's `old == new` is not rejected here; the rule prevents it. Construction stays mechanical.
- `line_text` is not part of `Edit`; N1 can add it later additively.
