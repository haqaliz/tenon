## Phase 1: Parse and resolve

- **Goal:** a valid list becomes a tuple of resolved paths.
- **Prerequisites:** none.
- **Files:** `repos.py`, `test_repos.py`.
- **Steps:**
  1. Write failing tests: comments/blanks/whitespace ignored; order preserved; relative paths
     resolve against the file's parent; absolute paths stay; `~` expands; nested relative works.
  2. Run — red; implement the loader; green.
- **Validation:** `uv run pytest tests/provider/test_repos.py -k "parse or resolve"`.
- **Commit:** `feat(provider): load a repos file`

## Phase 2: Errors and no existence check

- **Goal:** every bad list is a named error; listed paths may not exist.
- **Prerequisites:** Phase 1.
- **Files:** `repos.py`, tests.
- **Steps:**
  1. Write failing tests: empty/comment-only, missing file, a directory, non-UTF-8 bytes each raise
     a `ValueError` naming the file; a listed nonexistent path is returned.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/provider/test_repos.py`.
- **Commit:** `feat(provider): validate the repos file`

## Phase 3: Exports and the full suite
