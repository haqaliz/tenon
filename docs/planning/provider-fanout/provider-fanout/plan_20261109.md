## Environment & secrets

## Edge cases & error handling

- A missing path is a per-repo failure (exit 1); a bad list/bundle is a usage/config error (exit 2).
- A shared spec refusal aborts the run (exit 2); it is not attributed to repo 1.
- The single-repo path is byte-for-byte unchanged.
- The provider envelope for one repo is not reused; the fan-out has its own envelope.
