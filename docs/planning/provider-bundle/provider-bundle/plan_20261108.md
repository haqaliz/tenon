## Phase 1: Schema and loader

- **Goal:** a valid bundle object from JSON.
- **Prerequisites:** none.
- **Files:** `bundle.py`, `test_bundle.py`.
- **Steps:**
  1. Write failing tests: a full bundle loads with the expected fields/commands/require/
     breaking_only; the locate config is the right type; `description`/unknown keys ignored.
  2. Run — red; implement the dataclass and the JSON loader; green.
- **Validation:** `uv run pytest tests/provider/test_bundle.py -k valid`.
- **Commit:** `feat(provider): load a migration bundle`

## Phase 2: Paths and the source/language matrix

- **Goal:** relative specs and the config type.
- **Prerequisites:** Phase 1.
- **Files:** `bundle.py`, tests.
- **Steps:**
  1. Write failing tests: `old`/`new` resolve against the bundle dir; absolute paths work; a missing
     spec is an error; `mcp`+`ts` is an error; unknown source/language is an error.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/provider/test_bundle.py -k "path or matrix"`.
- **Commit:** `feat(provider): resolve migration specs and source`

## Phase 3: Validation and errors

- **Goal:** every bad bundle is a named error.
- **Prerequisites:** Phase 2.
- **Files:** `bundle.py`, tests.
- **Steps:**
  1. Write failing tests: missing/blank provider/migration/locate/sdk_package; a non-object locate;
     non-string mappings; a bad require; a non-array/empty command; a non-bool breaking_only; bad
     JSON; a missing file.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/provider/test_bundle.py`.
- **Commit:** `feat(provider): validate migration bundles`

## Phase 4: Exports and the full suite

- **Goal:** the package surface.
- **Files:** `__init__.py`, tests.
- **Steps:** export the two names; add a package import test; run the full suite.
- **Validation:** `uv run pytest` (1,635 + new tests).
- **Commit:** `feat(provider): export the migration bundle`
