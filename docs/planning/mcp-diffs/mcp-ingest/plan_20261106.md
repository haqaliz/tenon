## Phase 1: Loader and normalizer

- **Goal:** one name-keyed document from the envelope or a bare array.
- **Prerequisites:** none.
- **Files:** fixtures, `tests/detect/test_mcp_ingest.py`, `src/tenon/detect/mcp_ingest.py`.
- **Steps:**
  1. Write failing tests: the envelope and the bare array normalize to
     `{"tools": {name: tool}}`; `nextCursor`/extra keys ignored; `inputSchema`/`outputSchema`
     preserved; YAML and JSON both parse; the tool order does not matter.
  2. Run — red.
  3. Implement `parse_mcp` with `yaml.safe_load`, the envelope/array branch and the mapping.
  4. Run — green.
- **Validation:** `uv run pytest tests/detect/test_mcp_ingest.py -k loads`.
- **Commit:** `feat(detect): load MCP tools/list documents`

## Phase 2: Validation and named refusals

- **Goal:** bad input is a named refusal, never a partial document.
- **Prerequisites:** Phase 1.
- **Files:** `src/tenon/detect/mcp_ingest.py`, tests.
- **Steps:**
  1. Write failing tests: missing/non-list `tools`; non-mapping tool; empty/non-string name;
     duplicate name; non-mapping `inputSchema`/`outputSchema`; empty document; bad YAML/JSON with
     line/column. Each raises `SpecRefusal` with the right code/pointer.
  2. Run — red; implement the checks; green.
- **Validation:** `uv run pytest tests/detect/test_mcp_ingest.py -k "refus or invalid"`.
- **Commit:** `feat(detect): refuse malformed MCP tool documents by name`

## Phase 3: Local refs and cycles

- **Goal:** resolve local `$ref`s, refuse external ones, preserve a cycle marker.
- **Prerequisites:** Phase 2.
- **Files:** `src/tenon/detect/mcp_ingest.py`, fixtures, tests.
- **Steps:**
  1. Add fixtures: a tool schema with a local `#/...` ref; an external ref; a self-referential
     schema.
  2. Write failing tests: the local ref is resolved; an external ref is `EXTERNAL_REF`; a missing
     ref is `UNRESOLVED_REF`; a cycle does not crash and leaves a `{"$ref": ...}` marker.
  3. Run — red; reuse `resolve_refs` after normalization; green.
- **Validation:** `uv run pytest tests/detect/test_mcp_ingest.py -k ref`.
- **Commit:** `feat(detect): resolve local refs in MCP tool schemas`

## Edge cases & error handling

- A duplicate tool name is a refusal, not a last-wins merge.
- A tool with a non-mapping `inputSchema` is refused; an absent schema is valid.
- A cycle leaves the marker the differ will record as `CYCLIC_REF`.
- `nextCursor` is ignored; a paginated save is the caller's responsibility.
