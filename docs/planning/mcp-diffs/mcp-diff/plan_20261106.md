## Testing strategy

- Diff two committed normalized fixtures; no network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- Assert before/after payload shapes match T1's property records.
- Hash-seed stability via a subprocess or two sorted runs.

## Environment & secrets

- None.

## Edge cases & error handling

- A tool with no `inputSchema` contributes no schema changes.
- A schema with no `properties` is valid; `additionalProperties` still compares.
- A composition subtree is skipped and recorded; it never crashes or silently disappears.
- A removed+added tool pair stays two records; only property renames are inferred.
