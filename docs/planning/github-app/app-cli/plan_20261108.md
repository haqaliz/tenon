## Phase 1: Flags and construction

- **Goal:** `--remote app` builds the app remote.
- **Prerequisites:** `app-remote`.
- **Files:** `cli/main.py`, tests.
- **Steps:**
  1. Write failing tests: no `--remote` -> `GitGhRemote`; `--remote app --open-pr` with all flags
     constructs `GitHubAppRemote`/`GitHubAppToken` (monkeypatched classes record the args); the fake
     `write_pr` sees the remote.
  2. Run — red; implement the flags/`_remote(args)`; green.
- **Validation:** `uv run pytest tests/cli/test_main.py -k "app or remote"`.
- **Commit:** `feat(cli): use a GitHub App remote for tenon fix`
