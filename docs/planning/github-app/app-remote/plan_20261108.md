## Phase 1: Owner/repo, default branch and branch existence

- **Goal:** the read-only host operations.
- **Prerequisites:** `app-token`.
- **Files:** `github_app.py`, tests.
- **Steps:**
  1. Write failing tests: HTTPS/SSH origin URLs parse to owner/repo; a non-GitHub/relative URL is
     `RemoteError`; `default_branch` calls `GET /repos/{o}/{r}` and returns the field; a 200 branch
     check returns True, 404 False, 500 `RemoteError`; the token is minted once.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/pr/test_app_remote.py -k "parse or branch"`.
- **Commit:** `feat(pr): read GitHub App repository state`

## Phase 2: Token-safe push

- **Goal:** the proven branch pushed without the token in argv.
- **Prerequisites:** Phase 1.
- **Files:** `github_app.py`, tests.
- **Steps:**
  1. Write failing tests: the argv contains the credential helper and `origin <branch>`, no token,
     no `--force`; the env has `TENON_GITHUB_TOKEN`/`GIT_TERMINAL_PROMPT=0`; a failure is
     `RemoteError`; a stderr tail containing the token is redacted to `***`.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/pr/test_app_remote.py -k push`.
- **Commit:** `feat(pr): push with a GitHub App token safely`

## Phase 3: PR creation and exports

- **Goal:** the app-opened PR and the package surface.
- **Prerequisites:** Phase 2.
- **Files:** `github_app.py`, `__init__.py`, tests.
- **Steps:**
  1. Write failing tests: the POST body has head/base/title/body/draft; `html_url` is returned; a
     missing URL is `RemoteError`; the package export.
  2. Run — red; implement; green; run the full suite.
- **Validation:** `uv run pytest` (1,571 + new tests).
- **Commit:** `feat(pr): open GitHub App pull requests`

## Edge cases & error handling

- The origin parse supports `.git` and no suffix.
- The token is redacted from the git tail.
- A 404 branch is False; other API errors are `RemoteError`.
- The remote mints the token once.
