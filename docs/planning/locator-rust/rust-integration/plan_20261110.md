## Phase 1: Config and language plumbing

- **Goal:** `rust` is a valid language everywhere the config is built.
- **Prerequisites:** `rust-locate`.
- **Files:** `cli/config.py`, `cli/main.py`, tests.
- **Steps:**
  1. Write failing tests: `CliConfig(language="rust")`; `tenon.toml language = "rust"`;
     `--language rust --sdk-package <crate>` with no config; `mcp` + `rust` rejected; the error
     names python/ts/rust.
  2. Run — red; extend `LANGUAGES`, the literal, the messages and one locate-type dispatch table
     (used by `load_cli_config`, `overrides` and the no-config fallback); green.
- **Validation:** `uv run pytest tests/cli/test_main.py -k "language or rust"`.
- **Commit:** `feat(cli): accept the Rust language`

## Phase 2: Locator and bundle dispatch

- **Goal:** `check`/`fix`/`provider migrate` use the Rust locator.
- **Prerequisites:** Phase 1.
- **Files:** `cli/main.py`, `provider/bundle.py`, tests.
- **Steps:**
  1. Write failing tests: `_locate` dispatches rust; a Rust bundle loads with `RustLocateConfig`;
     `mcp`+rust and a bad crate are named bundle errors; the parser lists rust.
  2. Run — red; add the locator table and bundle dispatch; green.
- **Validation:** `uv run pytest tests/provider/test_bundle.py tests/cli/test_main.py -k "rust"`.
- **Commit:** `feat(cli): dispatch the Rust locator`

## Phase 3: Fixture, end-to-end and docs

- **Goal:** a real Rust checkout through check/fix and a bundle.
- **Prerequisites:** Phase 2.
- **Files:** fixture, tests, README, ARCHITECTURE.
- **Steps:**
  1. Add `tests/fixtures/repos/rust-basic/` with a `src/lib.rs` (a `use stripe::Charge;`, a
     `CreateCharge` literal bound and passed to `Charge::create`).
  2. Write failing tests: `tenon check --language rust` reports the call and field; `tenon fix`
     proposes the diff without writing; a Rust bundle runs through `provider migrate`.
  3. Run — red/green; document `--language rust`, the config and the limits.
- **Validation:** `uv run pytest` (1,843 + new tests); `uv run tenon check --help`.
- **Commit:** `docs: document the Rust locator`
