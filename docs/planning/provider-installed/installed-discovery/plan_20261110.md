## Phase 1: Discovery

- **Goal:** the installation's non-archived repos as a tuple.
- **Prerequisites:** none.
- **Files:** `installed.py`, tests.
- **Steps:**
  1. Write failing tests with a fake transport: one page; two pages with `per_page=2`; an empty page;
     archived skipped; order preserved; the request URL/page/Authorization header.
  2. Run — red; implement the dataclass and lister; green.
- **Validation:** `uv run pytest tests/pr/test_installed.py -k list`.
- **Commit:** `feat(pr): list the installation repositories`

## Phase 2: Malformed responses and the page cap

- **Goal:** every bad response is a named error.
- **Prerequisites:** Phase 1.
- **Files:** `installed.py`, tests.
- **Steps:**
  1. Write failing tests: missing/non-list `repositories`, a non-object item, blank `full_name`/
     `clone_url`, an API error, and the 100-page cap (always-full pages).
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/pr/test_installed.py -k "list and (error or cap)"`.
- **Commit:** `feat(pr): validate installation listings`

## Phase 3: Authenticated temp clone

- **Goal:** a clean checkout, removed afterwards, with no token leak.
- **Prerequisites:** Phase 2.
- **Files:** `github_app.py` (helper rename), `installed.py`, tests.
- **Steps:**
  1. Write failing tests: a local fixture clone yields the files and is removed on exit; a missing
     URL raises a named `RemoteError`; a fake runner whose stderr contains the token produces a
     scrubbed message; the temp dir is removed after failure; the child env has the token and
     `GIT_TERMINAL_PROMPT=0`, and the argv has no token.
  2. Run — red; rename the helper and implement `clone_repo`; green.
- **Validation:** `uv run pytest tests/pr/test_installed.py`.
- **Commit:** `feat(pr): clone an installation repo with the app token`

## Testing strategy

- Fake transports (the existing `(method, url, headers, body)` shape); `per_page=2` to keep
  pagination tests small; local fixture repos as `clone_url`; a fake runner for token scrub.
- One test per acceptance criterion, cited as `# Spec AC<n>`.

## Environment & secrets

- None; the token in tests is a literal like `ghs_test`.

## Edge cases & error handling

- A full page continues; a short/empty page stops; 100 pages is a named error.
- Archived repos are skipped, not counted.
- The temp dir is removed on success and failure.
- The token is scrubbed from every error string.
