## Testing strategy

- Unit: scan hits and chains, one-call invariant, two negatives.
- Integration: `locate` returns two certain sites and no ambiguity.
- Regression: full suite; `tests/locate/test_locate.py` unchanged and green.

## Edge cases

- Empty or one-segment chain: never strip (guard `len(chain) > 1`).
- `assert_called_with` on the production object (nonsense but parseable): rooted, so the rule
  applies; it is the same shape a test double has, and no real SDK exposes these methods.
- `assert_has_calls`, `call_args`, `assert_not_called`: unchanged; do not add to the set.
- A file with both a production call and an assertion: one operation call, two keyword sites.
