## Phase 2: the one-shot gate run

- **Files:** none in the repo; a throwaway script in `.cache/m0-3/run_gate.py`.
- **Steps:**
  1. Write the script:
     ```python
     import json
     from pathlib import Path

     from tenon.detect import ChangeKind, diff, load
     from tenon.locate import LocateConfig, locate
     from tenon.propose import propose
     from tenon.prove import prove

     repo = Path(".cache/m0-3/yezz").resolve()
     old = load(".cache/m0-3/v2500.json")
     new = load(".cache/m0-3/v2596.json")
     change = next(c for c in diff(old, new).changes if c.kind is ChangeKind.RENAMED)
     config = LocateConfig(
         sdk_package="stripe",
         operations={"POST /v1/checkout/sessions": "checkout.Session.create"},
     )
     located = locate(change, repo, config)
     proposal = propose(change, located, repo)
     python = Path(".cache/m0-3/venv-yezz/bin/python").resolve()
     result = prove(
         proposal,
         repo,
         [str(python), "-m", "pytest", "-q", "-k", "not setup_new_method"],
         timeout=120,
     )
     print(json.dumps({
         "change": change.to_dict(),
         "certain": [s.to_dict() for s in located.certain],
         "ambiguous": [g.to_dict() for g in located.ambiguous],
         "diff": proposal.diff,
         "level": result.level.value,
         "cause": result.cause.value if result.cause else None,
         "patch_applied": result.patch_applied,
         "baseline": result.baseline.to_dict() if result.baseline else None,
         "after": result.after.to_dict() if result.after else None,
     }, indent=2))
     ```
  2. Run it from the worktree root with `STRIPE_API_KEY=sk_test_x uv run python .cache/m0-3/run_gate.py`.
     The interpreter must be an **absolute** path: T4 executes the command with the copy as `cwd`.
  3. Expected: `level == "TESTS_PASSED"`; `baseline.returncode == 0` and
     `after.returncode == 0`; `patch_applied is True`; two certain sites; a two-hunk diff.
  4. If the result is not `TESTS_PASSED`, stop and record the actual cause. Do not tune the check
     until it is green; a narrowed check after a red result is a different run and must be declared.
- **Validation:** the printed JSON matches the pinning test's two sites and diff.
- **Commit:** none yet.

## Testing strategy

- The proof is the repo's check, not a Tenon test.
- The pinning test (aspect 2) guards the deterministic part in CI.
- The evidence is manual and one-shot; its reproducibility comes from the pinned hashes and the
  recorded package versions.

## Edge cases

- **Baseline red:** `TESTS_FAILED_BEFORE`; the gate stays open. Do not deselect more tests.
- **Patch does not apply:** `PATCH_DID_NOT_APPLY`; check the fixture diff against the clone (the
  clone is the same SHA, so this indicates the snapshot is not byte-identical).
- **After red:** `TESTS_FAILED_AFTER`; the scan rule did not cover the assertion, or the assertion
  changed shape. Record it; do not hand-edit the test.
- **Timeout:** raise `timeout` only if the baseline itself needs it; record the value.
- **`.cache` accidentally staged:** unstage before committing; never commit vendor documents.
