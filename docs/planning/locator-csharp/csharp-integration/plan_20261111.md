## Phase 1: Config and language plumbing

- **Goal:** `csharp` is a valid language everywhere the config is built.
- **Prerequisites:** `csharp-locate`.
- **Files:** `cli/config.py`, `cli/main.py`, tests.
- **Steps:**
  1. Write failing tests: `CliConfig(language="csharp")`; a temp `tenon.toml` with `language =
     "csharp"`; `--language csharp --sdk-package Stripe` with no config; `mcp` + csharp rejected;
     the error names python/ts/rust/go/csharp.
  2. Run — red; extend `LANGUAGES`, the literal, the messages and the `LOCATE_TYPES` build; green.
- **Validation:** `uv run pytest tests/cli/test_main.py -k "language or csharp"`.
- **Commit:** `feat(cli): accept the C# language`

## Phase 2: Locator and bundle dispatch

- **Goal:** `check`/`fix`/`provider migrate` use the C# locator.
- **Prerequisites:** Phase 1.
- **Files:** `cli/main.py`, `provider/bundle.py`, tests.
- **Steps:**
  1. Write failing tests: `_locate` dispatches csharp; a C# bundle loads with
     `CSharpLocateConfig`; `mcp`+csharp and a bad namespace are named bundle errors; the parser lists
     csharp.
  2. Run — red; add the locator table and bundle dispatch; green.
- **Validation:** `uv run pytest tests/provider/test_bundle.py tests/cli/test_main.py -k "csharp"`.
- **Commit:** `feat(cli): dispatch the C# locator`

## Phase 3: Fixture, end-to-end and docs

- **Goal:** a real C# checkout through check/fix and a bundle.
- **Prerequisites:** Phase 2.
- **Files:** fixture, tests, README, ARCHITECTURE.
- **Steps:**
  1. Add `tests/fixtures/repos/csharp-basic/` with a `.csproj` and `Program.cs` (`using Stripe;`,
     `using Stripe.Services;`, a `ChargeCreateOptions` initializer bound and passed to a
     `ChargeService` instance call).
  2. Write failing tests: `tenon check --language csharp` reports the call and property; `tenon fix`
     proposes the diff without writing; a C# bundle runs through `provider migrate`.
  3. Run — red/green; document `--language csharp`, the config and the limits.
- **Validation:** `uv run pytest` (2,013 + new tests); `uv run tenon check --help`.
- **Commit:** `docs: document the C# locator`
