## Testing strategy

  for policy tests; deterministic file order; no network/toolchain.
- One test per acceptance criterion, cited as `# Spec AC<n>`.

## Environment & secrets

- None; the grammar is a core dependency.

## Edge cases & error handling

- `using static` roots no type names; a dot/static member site is no site.
- A fluent chain is an unrooted hit, never certain.
- A simple name from an imported namespace roots a local type with the same name (documented).
- Rebinding a name clears the previous type.
