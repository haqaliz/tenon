## Phases

### Phase 1: Image and stack

- **Goal:** the artifacts exist and are internally consistent.
- **Steps:** write the Dockerfile (multi-stage `uv`, `--extra app`, git/CA, user 10001, owned /data,
  healthcheck, entrypoint/CMD), `.dockerignore`, compose (service+caddy, env, volumes, read-only,
  caps, healthcheck, no service port), Caddyfile, `.env.example`, bundle/secret layout and
  `.gitignore`.
- **Validation:** a YAML parse of the compose; a manual `docker build` is optional (the static tests
  cover the invariants).
- **Commit:** `feat(deploy): add the container and compose stack`

### Phase 2: Static tests and guide

- **Goal:** the invariants are asserted; the operator has a guide.
- **Steps:** write `tests/service/test_deploy.py` (Dockerfile USER/ENTRYPOINT/git/extra/no token;
  Compose services/volumes/read_only/cap_drop/no service ports; Caddyfile proxy; `.dockerignore`/
  `.env.example`/`DEPLOYMENT.md` keys); write `DEPLOYMENT.md` (secrets, key permissions, bundles,
  compose, TLS/local CA, backups/restore, rotation, upgrades, security checklist).
- **Validation:** `uv run pytest tests/service/test_deploy.py`; full suite.
- **Commit:** `docs: document the deployment` (includes the static tests)
