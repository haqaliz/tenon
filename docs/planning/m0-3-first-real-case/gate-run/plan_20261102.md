              customer=customer,

## Edge cases and error handling

- **Missing fixture (red).** `locate` on a missing root returns `NO_SDK_IMPORT`, not `NO_SITES`;
  the test fails for the intended reason. Once the fixture exists, the no-mapping result is
  `NO_SITES`.
- **Exact diff.** The fixture must end with a newline; the expected diff is pinned. A formatting
  change in the fixture fails the test on purpose.
- **Column.** The keyword starts after 8 spaces -> column 9.
- **Only one edit.** The fixture has one `payment_method_types`; `propose` must not emit a second.
- **No production change.** If a test needs a `src/tenon/` change to pass, stop and report; that
  would be a new card, not this one.
