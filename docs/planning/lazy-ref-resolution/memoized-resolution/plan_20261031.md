## Edge cases

- Cache key is the raw node id; the raw document stays alive during resolution, so ids cannot be
  reused.
- A list node is cached too; two refs to a list share it.
- A ref target that is a scalar: no cache needed; return it.
- A self-ref at the document root (`$ref: "#"`) returns the document itself; the active set prevents
  recursion.
- Do not cache the marker dict; each back-edge gets its own marker (they are cheap and may differ
  in ref string).
