## Edge cases

- A document with no components: both id sets are empty; `is_component_copy` returns `False` (the
  current early return can stay).
- A component that is a `$ref` to another: both names resolve to the same object; the id set has
  duplicates collapsed by the set.
- The root component is diffed even though its id is in the set (`root=True` guard unchanged).
- A ref to a sub-schema (not a whole component) is not a "component copy"; it is diffed at its use.
  That is the stricter identity rule; add a test if it is observable.
