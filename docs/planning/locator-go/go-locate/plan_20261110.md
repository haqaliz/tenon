## Phase 1: Config and the dependency

- **Goal:** a validated Go config.
- **Prerequisites:** none.
- **Files:** `pyproject.toml`, `go_config.py`, tests.
- **Steps:**
  1. Confirm `tree_sitter_go` imports; include the pyproject/lock change.
  2. Write failing tests: a valid root/package; blank/whitespace/leading-slash root and a bad
     package name are named `ValueError`s; mappings are read-only copies.
  3. Run — red; implement; green.
- **Validation:** `uv run pytest tests/locate/test_go_config.py`.
- **Commit:** `feat(locate): add the Go locate config`

## Phase 2: Imports, inference and calls

- **Goal:** root/subpackage imports, aliases and package calls as `Hit`s.
- **Prerequisites:** Phase 1.
- **Files:** `go_scan.py`, tests.
- **Steps:**
  1. Write failing tests on temp `.go` files: root and subpackage imports; alias; `_`/`.`; grouped
     imports; raw/interpreted strings; inference for `vN` and `-go`; `package_name` override; a file
     without the root is not a module; package calls with canonical chains; a method chain is an
     unrooted hit; a non-SDK selector is unrooted; skip `vendor`/`testdata`/hidden.
  2. Run — red; implement the parser cache, file walk, import extraction/inference and call hits;
     green.
- **Validation:** `uv run pytest tests/locate/test_go_scan.py -k "import or call or files"`.
- **Commit:** `feat(locate): scan Go imports and calls`

## Phase 3: Composite literals and field access

- **Goal:** field evidence on the right chain.
- **Prerequisites:** Phase 2.
- **Files:** `go_scan.py`, tests.
- **Steps:**
  1. Write failing tests: a standalone rooted literal's `KEYWORD` keys; an inline literal in a
     rooted call; a `var`/`:=` binding passed to a rooted call; a type-only `var`; a rebinding
     replaces the name; a field access through a binding is an `ATTRIBUTE` hit with the type and
     call chains; `&` unwrapping.
  2. Run — red; implement per-function binding tracking and call-argument attribution; green.
- **Validation:** `uv run pytest tests/locate/test_go_scan.py -k "literal or field or binding"`.
- **Commit:** `feat(locate): locate Go composite fields`

## Phase 4: The wrapper and policy integration

- **Goal:** the shared `LocateResult` for Go changes.
- **Prerequisites:** Phase 3.
- **Files:** `go_locate.py`, `__init__.py`, `test_go_locate.py`.
- **Steps:**
  1. Write failing tests: an operation change with a mapped `charge.New` and a field on the call

  2. Run — red; implement the wrapper and exports; green.
- **Validation:** `uv run pytest tests/locate/test_go_*.py`; full suite.
- **Commit:** `feat(locate): apply the certainty policy to Go`

## Testing strategy

- Temp `.go` files for scanner tests; `Change` fixtures copied from `tests/locate/test_rust_locate.py`
  for policy tests; deterministic file order; no network/toolchain.
- One test per acceptance criterion, cited as `# Spec AC<n>`.

## Environment & secrets

- None; the grammar is a core dependency.

## Edge cases & error handling

- `_`/`.` imports root no names; a dot-import site is no site.
- A method chain is an unrooted hit, never certain.
- A package clause the heuristic cannot infer needs `package_name`/an alias.
- Rebinding a name clears the previous type.
