## Edge cases

- `shutil.copytree(..., symlinks=True)` preserves links; do not follow them.
- The ignore callable receives `(directory, names)`; compare basenames, not paths.
- A root that is a file, not a directory → `CopyError`.
- Permissions preserved by `copytree`; do not add `copy_function` overrides.
- `git apply` from a copy with no `.git` works (verified: it is a standalone patch applier), so the
  skip list does not break application.
