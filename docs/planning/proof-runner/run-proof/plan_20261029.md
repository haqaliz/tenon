## Phases

### Phase 1: `run_check` (TDD)

- **Files:** `src/tenon/prove/run.py`, `tests/prove/test_run.py`
- **Steps:**
  1. Failing tests: a zero-exit command returns `returncode=0`, `timed_out=False`, `kind` echoed,
     command tuple; a non-zero command returns its code; a missing executable returns `127` with a
     message naming it; a sleep with `timeout=0.2` returns `timed_out=True`, `returncode=None`, and
     does not leave the child alive (assert within 1s by polling `proc.poll()` is not available here;
     instead assert the call returns within ~2s and `timed_out` is true).
  2. Tails: `stdout_tail`/`stderr_tail` capped via `tail`; a command printing 30 lines keeps the last
     20.
  3. Implement `run_check(command, cwd, kind, timeout)` with `subprocess.run(..., shell=False,
     text=True, capture_output=True, timeout=timeout, env=os.environ.copy())` and
     `TimeoutExpired` handling. Reject a string command and a non-positive timeout with `ValueError`.
- **Validation:** `uv run pytest tests/prove/test_run.py`
- **Commit:** `feat(prove): run one check with a timeout and capped output`

### Phase 2: `prove()` orchestration (TDD)

- **Files:** `src/tenon/prove/run.py`, `src/tenon/prove/__init__.py`, `tests/prove/test_prove.py`
- **Steps:**
  1. Preconditions: `command=[]`/`None` → `NO_TESTS_FOUND` and `copy_tree` is never called
     (monkeypatch it to raise); a string command → `ValueError`; `timeout<=0` → `ValueError`;
     no edits + `STALE_SITE` → `PATCH_DID_NOT_APPLY`; no edits + `NO_RULE` → `NO_PATCH_PROPOSED`.
  2. End-to-end: build the rename proposal over `proof-basic` through T1→T2→T3, run
     `[sys.executable, "-c", "import acme.billing"]` → `TESTS_PASSED`, both checks green,
     `patch_applied=True`.
  3. Red baseline: `[sys.executable, "-c", "raise SystemExit(1)"]` → `TESTS_FAILED_BEFORE`,
     `after=None`, `patch_applied=False`.
  4. Broken patch: fake proposer `amount → 1bad`, same import command → `TESTS_FAILED_AFTER`,
     `patch_applied=True`.
  5. Garbage diff: `Proposal(..., diff="nope")` → `PATCH_DID_NOT_APPLY`.
  6. Timeout on baseline: sleep command, `timeout=0.2` → `CHECK_TIMED_OUT`.
  7. Copy failure: monkeypatch `copy_tree` to raise `OSError` → `COPY_FAILED`.
  8. Read-only: hash every file under `proof-basic` before/after the end-to-end case.
  9. Determinism: the same `ProofResult` serializes identically across hash seeds.
  10. Implement `prove()` in the documented order, using `isolated_copy` and `apply_diff`; map
      failures to causes; export `prove`, `ProofLevel`, `ProofCause`, `ProofResult`, `CheckResult`.
- **Validation:** final full suite, then the manual check.
- **Commit:** `feat(prove): baseline, apply and run the check to assign a proof level`

## Edge cases

- A baseline timeout is `CHECK_TIMED_OUT`, not `TESTS_FAILED_BEFORE`; `after` stays `None`.
- `patch_applied=True` with `CHECK_TIMED_OUT` on the after check: the patch did apply, say so.
- A command that exits 127 because the executable is missing is still a failed check, not
  `NO_TESTS_FOUND`.
- The copy must be gone before `prove` returns, including on exceptions; use `with isolated_copy`.
- A diff that applies but changes nothing (`returncode=0`, no-op) is still `TESTS_PASSED`; the
  proposal invariant prevents empty edits, and this card does not second-guess git.
