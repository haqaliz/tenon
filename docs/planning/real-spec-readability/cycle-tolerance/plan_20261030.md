## Edge cases

- A `$ref` marker at the top of a component schema: `_diff_components` calls `_diff_schema`; the
  guard records and returns, so the component is not diffed.
- Two cycles in one document: dedupe by `(pointer, reason)`.
- A marker on one side only: skip the pair; no invented change.
- `_component_canons` must tolerate markers (it hashes the resolved dict; fine).
