## Edge cases

- A whole component schema that is `oneOf`: `_diff_components` → `_diff_schema` → `_flatten` returns
  `None`; no change, one entry.
- A parameter schema that is `anyOf`: skip the type comparison for that parameter; the parameter's
  presence/removal records still work.
- A plain `allOf` whose members include a `$ref` marker: the merge sees `{"$ref": ...}` → record
  `CYCLIC_REF` for that member and return `None` for the whole merge (do not partially merge).
- Dedupe: the same pointer can be reached from old and new; one entry per `(pointer, reason)`.
