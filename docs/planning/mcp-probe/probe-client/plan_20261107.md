## Phase 1: Spawn, handshake and close

- **Goal:** a live stdio session against the fake server.
- **Prerequisites:** none.
- **Files:** fake server, `client.py`, `test_client.py`.
- **Steps:**
  1. Write failing tests: start the fake server; `initialize` returns the protocol version/server
     info; `notifications/initialized` is sent before `tools/list`; `close` leaves no process.
  2. Run — red.
  3. Implement spawn, the JSON-RPC line writer/reader, ids, initialize and close; the fake server
     answers initialize/notifications.
  4. Run — green.
- **Validation:** `uv run pytest tests/probe/test_client.py -k "start or init"`.
- **Commit:** `feat(probe): start an MCP stdio session`

## Phase 2: Tools with pagination

- **Goal:** list every tool, following the cursor.
- **Prerequisites:** Phase 1.
- **Files:** `client.py`, fake server, tests.
- **Steps:**
  1. Write failing tests: page one returns a cursor and page two the rest; `list_tools` returns both;
     no cursor ends the loop.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/probe/test_client.py -k tools`.
- **Commit:** `feat(probe): list MCP tools across pages`

## Phase 3: Tool calls and JSON-RPC errors

- **Goal:** call a tool and surface a server error.
- **Prerequisites:** Phase 2.
- **Files:** `client.py`, fake server, tests.
- **Steps:**
  1. Write failing tests: `echo` returns its content; `fail` returns `isError: true` as a result;
     an unknown tool's JSON-RPC error raises `ProbeError` with a reason/detail.
  2. Run — red; implement; green.
- **Validation:** `uv run pytest tests/probe/test_client.py -k call`.
- **Commit:** `feat(probe): call MCP tools over stdio`

## Phase 4: Timeouts, closed pipes, server requests, determinism

- **Goal:** never hang or crash on a bad server.
- **Prerequisites:** Phase 3.
- **Files:** `client.py`, fake server variants, tests.
- **Steps:**
  1. Write failing tests: a server that exits, a malformed line, a mismatched id, a timeout, and an
     unknown server request answered with `-32601`; `close` captures the stderr tail.
  2. Run — red; implement the timeout/error mapping and the server-request reply; green.
  3. Run the full suite.
- **Validation:** `uv run pytest tests/probe/test_client.py` and `uv run pytest`.
- **Commit:** `feat(probe): fail MCP connection errors by name`

## Testing strategy

- The fake server is a committed Python script spawned with `sys.executable`; no network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- Assert reasons, not raw tracebacks; assert the process is gone after close.

## Environment & secrets

- None.

## Edge cases & error handling

- A server writing logs to stdout is a JSON error -> `ProbeError`.
- A timeout kills the server; the client does not retry.
- An unknown server request gets `-32601`; the client keeps reading.
- The stderr tail is capped.
