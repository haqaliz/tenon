## Testing strategy

- Fake server/agent fixtures; no network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- Assert the report has no timestamps/temp paths and the JSON is stable.

## Environment & secrets

- None.

## Edge cases & error handling

- An agent plan with no calls and no expectations passes vacuously; the report shows zero calls.
- A failed call is recorded; later calls still run.
- A server error before any task is `ProbeError` (exit 2); a tool error is a failed task (exit 1).
- The report caps descriptions/excerpts.
