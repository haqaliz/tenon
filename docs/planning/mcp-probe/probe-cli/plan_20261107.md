## Testing strategy

- The CLI tests spawn the committed fake server/agent; no network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- The existing check/fix tests are the regression guard.

## Environment & secrets

## Edge cases & error handling

- A task failure is a report, exit 1; a setup failure is an error object, exit 2.
- `--timeout` must be positive; a non-number is argparse exit 2.
- The probe does not read `tenon.toml` in this card.
- The `server-cmd`/`agent-cmd` are `shlex`-split; a bad quote is a usage error.
