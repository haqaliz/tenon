## Phases

### Phase 1: Parse and version gate (TDD)

- **Files:** `src/tenon/detect/ingest.py`, `tests/detect/test_ingest.py`,
  `tests/fixtures/specs/minimal-3.0.yaml`, `tests/fixtures/specs/minimal-3.1.json`
- **Steps:**
  1. Fixtures: a minimal valid 3.0.x YAML spec and a 3.1.x JSON spec (one path, one operation).
  2. Failing tests: both load to a dict; a Swagger 2.0 doc raises `UNSUPPORTED_VERSION`; a plain
     YAML file (`foo: bar`) raises `NOT_A_SPEC`; a YAML syntax error raises `UNPARSEABLE`.
  3. Implement `parse(text, source)` using `yaml.safe_load`; catch `yaml.YAMLError` → `UNPARSEABLE`
     with `problem_mark.line/column`.
  4. Implement the version gate: `openapi` string startswith `"3.0."` or `"3.1."`.
  5. Implement `load(path)` reading UTF-8 and delegating to `parse`, including the path in messages.
- **Validation:** `uv run pytest tests/detect/test_ingest.py`
- **Commit:** `feat(detect): load and version-gate OpenAPI 3.x documents`

### Phase 2: Local $ref resolution (TDD)

- **Files:** `src/tenon/detect/ingest.py`, `tests/detect/test_ingest.py`
- **Steps:**
  1. Tests: `A → B → C` chain resolves to the final node; `#/components/schemas/Missing` raises
     `UNRESOLVED_REF`; `https://example.com/x.yaml` raises `EXTERNAL_REF`; a self-referential `$ref`
     raises `UNRESOLVED_REF` (chosen cycle policy: refuse, see spec open question).
  2. Implement `resolve_refs(doc) -> dict`: deep copy, walk all `$ref` strings, dereference locals,
     track visited pointers for cycle detection, rewrite with `json.dumps`-free plain dict traversal.
  3. Implement RFC 6901 pointer unescaping (`~1` → `/`, `~0` → `~`).
  4. `load()`/`parse()` return the resolved document; the raw document is not exposed.
- **Validation:** `uv run pytest tests/detect/test_ingest.py`
- **Commit:** `feat(detect): resolve local $refs and refuse external or cyclic refs`

## File-by-file build order

1. `src/tenon/detect/ingest.py` — `load`, `parse`, `resolve_refs`. Depends on `record.SpecRefusal`.
2. `tests/fixtures/specs/*` — inputs only.
3. `tests/detect/test_ingest.py`.

## Testing strategy

- Fixtures on disk; no network calls anywhere in the suite (assert by not importing any HTTP client).
- Malformed-input table test: one parametrised test mapping (fixture, expected code) so a new refusal
  case costs one row.

## Edge cases

- YAML 1.1 booleans: `safe_load` turns `on`/`off` into bools; specs with unquoted `on:` keys. Not
  worth handling — document if seen in a real spec.
- Empty file and `null` document → `UNPARSEABLE` / `NOT_A_SPEC` respectively, never `AttributeError`.
- `openapi: 3.0` (no patch) is not a valid version string → `UNSUPPORTED_VERSION`.

## Agent execution notes

- Do not add a `--strict` flag or schema validation. Refusals only for what this spec lists.
- If a real fixture needs `$ref` into a sibling file, stop: that is the `EXTERNAL_REF` refusal, not a
  feature.
