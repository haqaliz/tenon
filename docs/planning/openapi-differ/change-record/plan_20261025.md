## Phases

### Phase 1: Contract types (TDD)

- **Files:** `src/tenon/detect/record.py`, `tests/detect/test_record.py`
- **Steps:**
  1. Write tests: each of the 13 `ChangeKind` values constructs a `Change`; `to_dict()` →
     `from_dict()` round-trip equality.
  2. Write tests for refusal: `SpecRefusal(code=..., pointer=..., message=...)` renders code and
     pointer in `str()`; constructing with a non-enum code raises `TypeError`.
  3. Write tests for JSON safety: `json.loads(result.to_json())` succeeds and contains no tuples.
  4. Implement `ChangeKind` (str `Enum`), `Location`, `Change`, `SpecRefusal`, `DiffResult`.
  5. `Change` is `@dataclass(frozen=True, slots=True)`; `DiffResult` stores a tuple, not a list, so
     it cannot be mutated after ordering.
- **Validation:** `uv run pytest tests/detect/test_record.py`
- **Commit:** `feat(detect): add typed Change record and refusal vocabulary`

### Phase 2: Canonical ordering + byte-stable JSON (TDD)

- **Files:** `src/tenon/detect/record.py`, `tests/detect/test_record.py`
- **Steps:**
  1. Tests: the same 4 changes inserted in two different orders produce identical `to_json()`.
  2. Test: subprocess run with `PYTHONHASHSEED=0` and `=1` produce identical bytes.
  3. Implement `DiffResult.__init__` sorting by `(pointer, kind, before_key, after_key)` with
     `json.dumps(..., sort_keys=True, ensure_ascii=False)` for the keys.
  4. Implement `to_json()` with `separators=(",", ":")` and `ensure_ascii=False`.
- **Validation:** `uv run pytest tests/detect/test_record.py`; the hash-seed test spawns
  `sys.executable -c`.
- **Commit:** `feat(detect): canonical ordering and byte-stable JSON for change records`

## Testing strategy

- Unit only; no I/O, no network. `uv run pytest` must be green before each commit.
- The hash-seed test is the only subprocess test; keep it in `test_record.py`.

## Edge cases

- `before`/`after` may hold nested dicts (a whole schema). Serialization must deep-copy or
  normalise them so a caller mutating its input cannot alter an already-built record.
- `pointer` must be RFC 6901: `~` → `~0`, `/` → `~1`. Validate with one test using a path
  containing a slash.
- `kind` in `to_dict()` serialises as its string value, never `"ChangeKind.X"`.
