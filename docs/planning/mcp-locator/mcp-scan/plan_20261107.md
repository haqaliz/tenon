## Phase 1: Evidence and reachability

- **Goal:** a canonical `McpScan` over the files that reach the MCP client package.
- **Prerequisites:** none.
- **Files:** fixture, `src/tenon/locate/mcp_scan.py`, `tests/locate/test_mcp_scan.py`.
- **Steps:**
  1. Write failing tests: a file importing `mcp` is in `modules`; a transitive local importer is
     scanned; an unrelated file is not; no import -> empty `modules`; a syntax-error file is skipped.
  2. Run — red.
  3. Implement `McpHit`/`McpDynamic`/`McpScan` and reuse the T2 `.py` read/reachability helpers.
  4. Run — green.
- **Validation:** `uv run pytest tests/locate/test_mcp_scan.py -k reach`.
- **Commit:** `feat(locate): discover MCP client modules`

## Phase 2: Client rooting

- **Goal:** a `ClientSession` receiver is rooted, a parameter is not.
- **Prerequisites:** Phase 1.
- **Files:** `src/tenon/locate/mcp_scan.py`, fixtures, tests.
- **Steps:**
  1. Write failing tests: `async with ClientSession(...) as session` rooted; `session =
     ClientSession(...)` rooted; a direct `ClientSession(...).call_tool` rooted; a parameter
     unrooted; a two-hop alias -> `ALIAS_CHAIN`.
  2. Run — red; add the with/async-with binding pass and the direct-receiver check; green.
- **Validation:** `uv run pytest tests/locate/test_mcp_scan.py -k root`.
- **Commit:** `feat(locate): root MCP client sessions`

## Phase 3: `call_tool`, tool name and argument keys

- **Goal:** evidence for the call, the literal tool and the argument keys.
- **Prerequisites:** Phase 2.
- **Files:** `src/tenon/locate/mcp_scan.py`, fixtures, tests.
- **Steps:**
  1. Write failing tests: a positional tool literal and a `name=` literal; a variable name -> a
     `GETATTR` dynamic; a `call` hit with the exact line/column; dict keys -> `dict_key` at the
     quote; `dict(amount=1)` -> `keyword`; a nested object key is not emitted.
  2. Run — red; implement the call visitor/argument extraction; green.
- **Validation:** `uv run pytest tests/locate/test_mcp_scan.py -k "call or args"`.
- **Commit:** `feat(locate): scan MCP call_tool sites`

## Phase 4: Dynamics, columns, determinism

- **Goal:** the unprovable constructs and byte-stable evidence.

## Testing strategy

## Environment & secrets

- None.

## Edge cases & error handling

- A parameter session is unrooted; a factory-returned session is unrooted.
- A syntax-error file is skipped.
- A tool name variable is a dynamic, not a site.
- A dict value expression is not walked; only top-level keys.
