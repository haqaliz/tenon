## Testing strategy

- The MCP check test uses the real locator on a committed Python fixture.
- The MCP fix test monkeypatches `prove_plan`; T4's proof is tested elsewhere. No MCP server/network.
- One test per acceptance criterion, cited as `# Spec AC<n>`.
- JSON determinism across hash seeds for an MCP check report.

## Edge cases & error handling

- `source=mcp` + `language=ts` is a named usage error.
- A missing `tenon.toml` with `--source mcp` uses `sdk_package="mcp"`.
- The `[locate] operations`/`fields` tables are ignored in MCP mode; the tool name comes from the
  change.
- The `unanalyzed` from `diff_mcp` reaches `write_pr`.
